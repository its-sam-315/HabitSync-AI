# 🚀 HabitSync AI

**HabitSync AI** is an offline-first, privacy-focused smart habit tracker that helps you build meaningful routines and stay consistent using in-browser AI insights. No login, no cloud — just you and your progress.

---

## ✨ Features

- ✅ Add daily/weekly/monthly habits
- 📊 View streaks, progress heatmaps, and analytics
- 🤖 Get AI-powered habit suggestions & consistency feedback
- 🔔 Smart, auto-adjusting reminders
- 📶 Works 100% offline as a PWA (Progressive Web App)
- 🔒 No signup, no tracking — your data stays with you
- 📤 Export/Import habit data easily (JSON or CSV)

---

## 🧠 Why It’s Special

Unlike basic habit trackers, **HabitSync AI** understands your habit trends and actively recommends adjustments to optimize your routine. Think of it as your personal productivity coach — always available, even offline.

---

## 🛠️ Tech Stack

- **Frontend:** React + TailwindCSS  
- **Storage:** IndexedDB (via idb)  
- **AI Engine:** TensorFlow.js / in-browser ML logic  
- **PWA:** Offline-first with service worker  
- **Hosting:** GitHub Pages (free & fast)
